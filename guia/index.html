O que é

Uma API multimodal gratuita — com letras miúdas

A Agnes AI, da Sapiens AI (Singapura), oferece modelos próprios de texto, visão, imagem e vídeo por uma API compatível com OpenAI. "Gratuito" significa sem cobrança por token ou geração — não uso irrestrito, garantido ou adequado para produção crítica.

💸 Custo excepcional

Texto, imagem e vídeo atualmente a US$ 0 — inclusive via API. Uma das ofertas gratuitas mais agressivas de 2026.

🔌 Compatível com OpenAI

Mesmo formato de chamada dos SDKs OpenAI: integra em n8n, Python, Node, agentes e apps existentes trocando só a base URL e a chave.

⚠️ Sem SLA no free

Sem garantia de uptime, limites podem mudar, e no plano gratuito seus dados podem treinar os modelos (salvo opt-out). Não use como único fornecedor em sistema crítico.

Modelos

Os três modelos principais

Uma única chave e um único gateway (apihub.agnes-ai.com) para texto/visão, imagens e vídeo.

💬 Agnes 2.0 Flash

Texto, visão e agentes. Conversa, raciocínio, código, tool calls, streaming e visão por URL de imagem. Contexto declarado de 512K tokens (catálogos externos citam 256K — teste antes de mandar contextos enormes). US$ 0 por milhão de tokens.

POST https://apihub.agnes-ai.com/v1/chat/completions
model: agnes-2.0-flash

🖼️ Agnes Image 2.1 Flash

Texto→imagem, imagem→imagem, redesenho, edição por instrução, retorno em URL ou Base64, resoluções de 1K a 4K nas proporções 1:1, 16:9, 9:16, 4:3, 3:4, 2:3, 3:2 e 21:9. US$ 0 por imagem.

POST https://apihub.agnes-ai.com/v1/images/generations
model: agnes-image-2.1-flash

🎬 Agnes Video V2.0

Texto→vídeo, imagem→vídeo, keyframes, controle de câmera/movimento por prompt, 480p/720p/1080p, geração assíncrona. Até 441 frames por pedido (fórmula 8n+1). US$ 0 por segundo.

Como funciona

Integração em minutos, arquitetura em camadas

Como a API é compatível com OpenAI, o caminho é o de sempre — e a arquitetura mais segura usa a Agnes como camada gratuita de alto volume, nunca como cérebro único.

Criar conta + chave→ Apontar SDK p/ apihub.agnes-ai.com→ Chamar texto / imagem / vídeo→ Fallback p/ outro fornecedor

🅰️ Camada Agnes

Tarefas gratuitas e de alto volume: thumbnails em lote, resumos, classificação, agentes de teste, vídeos experimentais.

Guia de uso · passo a passo

Da chave à primeira geração

Tudo pelo endpoint compatível com OpenAI. Troque $AGNES_API_KEY pela sua chave.

1

Crie a conta e a chave de API

Cadastre-se pela campanha oficial — agnes-ai.com/campaign — e gere uma chave gratuita. Guarde-a como variável de ambiente — nunca no código.

# acesso: https://agnes-ai.com/campaign
export AGNES_API_KEY="sua-chave-aqui"
2

Texto e agentes — Agnes 2.0 Flash

Chat completions no formato OpenAI, com streaming e tool calls.

curl https://apihub.agnes-ai.com/v1/chat/completions \
  -H "Authorization: Bearer $AGNES_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"agnes-2.0-flash","messages":[{"role":"user","content":"Resuma o que é a Agnes AI em 3 frases."}]}'
3

Ou use o SDK OpenAI apontando pro gateway

Em Python (ou Node), basta trocar base_url — o resto do código não muda.

# pip install openai
from openai import OpenAI
client = OpenAI(base_url="https://apihub.agnes-ai.com/v1", api_key="$AGNES_API_KEY")
r = client.chat.completions.create(model="agnes-2.0-flash",
    messages=[{"role":"user","content":"Olá!"}])
print(r.choices[0].message.content)
4

Imagens — Agnes Image 2.1 Flash

Ex.: thumbnail 16:9 em 2K (depois redimensione para 1920×1080).

curl https://apihub.agnes-ai.com/v1/images/generations \
  -H "Authorization: Bearer $AGNES_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"agnes-image-2.1-flash","prompt":"thumbnail de YouTube sobre IA gratuita, estilo tech dark","size":"2K","ratio":"16:9"}'
5

Vídeo — Agnes Video V2.0 (assíncrono)

Cria o job, recebe um video_id e consulta até ficar pronto. Frames seguem a fórmula 8n+1 (máx. 441).

# criar
curl https://apihub.agnes-ai.com/v1/videos \
  -H "Authorization: Bearer $AGNES_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"agnes-video-v2.0","prompt":"drone sobrevoando cidade futurista ao entardecer","resolution":"720p"}'

# consultar o resultado
curl "https://apihub.agnes-ai.com/agnesapi?video_id=SEU_ID" \
  -H "Authorization: Bearer $AGNES_API_KEY"
6

Faça o opt-out de treinamento (importante!)

No plano gratuito, prompts e arquivos podem ser usados para treinar os modelos, salvo opt-out — disponível dentro do serviço ou pelo suporte. Nunca envie dados sensíveis (CPF, pacientes, contratos, chaves, dados LGPD) pelo free.

# canal de suporte para exclusão do uso em treinamento
support@agnes-ai.com
Desempenho

O que os números dizem (e o que não dizem)

A evidência é boa em agentes e razoável em imagem; em vídeo, o modelo fica longe dos líderes. Faltam benchmarks amplos e independentes de texto (SWE-bench, GPQA, MMLU-Pro etc.).

🤖 Texto/agentes

Claw-Eval: Pass³ 60,9% — 9º lugar (líder do snapshot: Claude Opus 4.6 com 70,4%). Benchmark legítimo de 300 tarefas reais verificadas por humanos. Competitivo, mas não líder — e um único benchmark não prova superioridade geral em código, português, matemática ou factualidade.

🖼️ Imagem

~1.178–1.184 Elo em avaliações de edição: funcional e competitivo. Ótimo para alternativas de thumbnail, banners, fundos e testes A/B; para peças premium (mãos, tipografia, logotipo exato), revise ou finalize em modelo mais forte.

🎬 Vídeo

Posições ~61 (T2V) e ~63 (I2V) nos rankings — abaixo dos líderes em realismo e movimento complexo. Antes do free, custava ~US$ 0,30/min em gateways. A US$ 0, compensa testar intensamente para cenas de apoio e volume.

Vale a pena? Sim — com fallback

A oferta é forte demais para ignorar em testes, conteúdo, agentes e automações não críticas. Mas não como fornecedor único de sistema comercial crítico.

  • Atendimento médico/odontológico, financeiro, jurídico;
  • Dados pessoais protegidos (LGPD) no plano free;

  • Geração em que a qualidade final precisa ser previsível;
  • Sistemas comerciais sem fallback.
